# Изменения под конкретную комплектацию Lily58

- Плата: `nice_nano_v2` (совместимые ProMicro nRF52840).
- Две половины: `Lily58_L` и `Lily58_R`.
- Дисплеи: обычные SSD1306 128x32 через `nice_oled`.
- Энкодеры и их sensor-bindings удалены.
- Сборки nice!view и dongle удалены; оставлены только две прошивки половин.
- Bongo Cat оставлен как анимация набора; числовой WPM, спидометр и график отключены.
- Анимация Cat на периферийном дисплее оставлена.
- Для OLED включена отдельная очередь с приоритетом 10, чтобы обновление дисплея уступало обработке клавиш.
- Сохранены исходные debounce 5/5 мс, BLE TX power +8 dBm, таймауты сна и параметры RGB.

`zmk-for-PandaKB.com-` оставлен в west manifest: его содержимое не входит в приложенный архив, поэтому без проверки нельзя безопасно объявить его ненужным.

Сборка в этой среде не запускалась: архив подготовлен как набор изменений, но совместимость внешних west-модулей и итоговые UF2 ещё нужно проверить GitHub Actions.
